## system information saver
![Static Badge](https://img.shields.io/badge/script-blue)

![Static Badge](https://img.shields.io/badge/bash-blue?style=for-the-badge&logo=gnubash&labelColor=000000)


Simple bash script to get logs, information and status on SUT, copies file and creates a folder to save and analize
later.


May run on linux systems **with or with out** graphic display.

Tested on **Red Hat, OpenSuse, CentOS, yocto**

**Usage :**

* Copy to a folder
* Open a terminal
* Run with ./system\_info.sh
* Wait
* Copy the folder created



**Notes:**

May change the way this works as new tools and changes are done on the system commands get updated.
